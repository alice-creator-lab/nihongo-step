# 日語階梯 nihongo-step

跟隨初級 40 課的編排，一課一課學日語的單頁應用程式。手機優先，離線可用，進度只存在使用者的裝置。

線上版本：<https://alice-creator-lab.github.io/nihongo-step/>

## 目前狀態

內容 40 課（第 1–4 冊）已全部撰寫完成，功能已完成四項：

- **F1 課程地圖與進度** — 4 冊 40 課的完整結構，40 課全部開放；每一課顯示完成百分比（已看段數 ÷ 六段）與行底進度線，首頁顯示整體進度、「繼續學習」入口；進度存於 localStorage。
- **F2 課堂頁骨架** — 每課固定六段：句型、單字、文法、練習、會話、文化；分頁導航、已讀標記、標記本課完成。
- **F3 單字卡自測** — 於「單字」段抽 10 個字，可選日→中或中→日；先回想再翻卡，按「記得」或「不記得」，結算顯示分數與漏記的字，可重練漏記的部分。
- **F4 文型練習自動評分** — 於「練習」段逐題作答，比對時忽略空白、標點與全半形差異，並接受數種常見寫法；答錯顯示正確答案。翻譯題沒有唯一答案，改為顯示參考答案後由使用者自評。
- **F5 會話角色扮演** — 於「會話」段選「我演 李／我演 田中」，系統先播對方的句子，再顯示你要說的句子；可聽示範、錄音後回放對照，最後顯示完成句數並可交換角色重來。錄音只在裝置內播放，不上傳。
- **跟讀評分** — 會話每句右邊的麥克風按鈕（或角色扮演中「跟讀評分」）可收音朗讀：系統以語音辨識取得你唸的假名，與該句假名逐字比對，給 0–100 分，並把沒對上的音標紅，同時顯示「系統聽到」的內容與該句最高分。分數是假名對上的比例，不是發音考試成績。
- **F6 聽力練習** — 「練習」段可切換「文型練習／聽力」。聽力題自動播放句子，四選一選出正確意思，可重播或慢速重播；答錯會顯示原句並記入錯題簿。

單字自測、文型練習與聽力共用一個錯題簿：答錯的單字與題目自動記錄，課程地圖可開啟清單查看或清除。

朗讀評分的限制：iPhone 要用 **Safari 直接開網址**（「加到主畫面」的版本在 iOS 不支援語音辨識），並需開啟「Siri 與搜尋」及麥克風權限；辨識由瀏覽器／系統的語音服務處理，音訊會離開裝置。不支援的瀏覽器會顯示提示，並提供「錄音對照」（自己唸一次，再與示範交替播放比較）。

其他已可用：日語語音示範（瀏覽器語音合成，可切換慢速）、會話整段播放與中譯隱藏。

尚未實作：F7 漢字讀音、F8 複習排程（錯題目前只記錄，未排程）、F9 小測、F10 離線細節與備份匯出。

## 目錄

```
index.html            應用程式（版面、樣式與邏輯都在此檔）
data/course.json      4 冊 40 課的課名、級別與開放狀態
data/lesson-L##.json  各課內容（lesson-L01.json 至 lesson-L40.json）
sw.js                 Service Worker，採網路優先策略
manifest.webmanifest  主畫面安裝設定
icons/                應用程式圖示
tools/validate.mjs    內容校驗腳本
```

## 本機預覽

```bash
python3 -m http.server 8812
# 開啟 http://127.0.0.1:8812/
```

課程資料以 `fetch` 載入，必須經 HTTP 伺服器開啟，直接雙擊 `index.html` 會載入失敗。

## 內容校驗

```bash
node tools/validate.mjs
python3 tools/audit_readings.py --strict   # 例句讀音是否跟單字表一致
```

`tools/audit_readings.py` 把每句 `ja` 與 `kana` 對齊，逐一核對漢字詞的讀音是否跟 40 課單字表一致，並列出讀音不同但已核可的用法（`data/readings-allow.json`，例如「間に合う」的 間 讀 ま、「一日に」讀 いちにち）。加 `--by-lesson` 可逐課看結果，`--verbose` 會列出細節。因為音檔就是用 `kana` 合成的，這支腳本同時就是音檔讀音的檢查。

檢查 `course.json` 是否為 4 冊 40 課、課號有無重複，以及每一課 JSON 的欄位與會話、練習是否完整。

練習題的 JSON 需要 `type` 欄位：`fill`（填一格）、`rewrite`（改寫整句）需附 `answers` 陣列列出可接受寫法；`free`（翻譯）附 `model` 作參考答案。新增題目時，`answers` 要包含學生可能寫出的等價形式。

## 內容來源

課程順序參照初級綜合教材《日本語GOGOGO》公布的 40 課文型表；課名、例句、會話、文法說明、練習題與文化專欄全部自行編寫，不採用原書文字、圖片或錄音。每冊的單字數與句型數（498／48、456／41、565／36、459／43）為該教材公布的統計，只作進度參考。

## 五十音頁（由 kana-dojo 併入）

- `kana/index.html` 是原本 Kana Dojo 的單檔練習頁（羅馬拼音／鍵盤輸入／手寫／讀音四種模式），連 `kana/kana-templates.json`（手寫辨識模板）一併放在本站；入口在地圖「第一冊」之上的五十音區塊。
- 併入時做了三件事：header 加返回地圖箭頭；移除它自己的 manifest／圖示（`/kana/` 下會 404）；停用它原本的 `sw.js` 註冊（兩個 SW 爭同一個 scope），快取與更新交給根目錄 `sw.js`（已把 `kana/index.html`、`kana/kana-templates.json` 加入 `SHELL`）。
- 更新方式：重新抓 kana-dojo 的 index.html／kana-templates.json 覆蓋，再套用上面三項改動。

## 技術說明

- 純前端，無建置步驟、無外部依賴；字體使用系統的日文與繁中字型。
- 發音優先用預製人聲：`tools/make_audio.py` 以 edge-tts（ja-JP-KeitaNeural／NanamiNeural）合成，音檔放在 `audio/`，索引在 `data/audio.json`（key 分 `d`會話、`v`單字、`p`句型例句、`g`文法例句、`l`聽力）。只有缺音檔時才退回 `speechSynthesis`。
- 朗讀文字由 `tools/speech.py` 產生：以句子自己的 `kana` 為準（「町」一定是 まち，不會被 TTS 讀成 ちょう），再把助詞 は／へ／を 改寫成 わ／え／お，因為整句假名時 edge-tts 會把助詞「は」讀成 ha（實測：漢字句讀 wa，假名句讀 ha）。單字表以外的漢字保留漢字，交給 TTS 依上下文判斷。
- 改動 `kana` 之後要跑 `python3 tools/make_audio.py --force-ex` 重生句子音檔（會話、句型例句、文法例句、聽力；單字不動），它會把 `data/audio.json` 的 `v` 加一，令瀏覽器重抓音檔。
- 「慢速」是把同一段人聲以 `playbackRate = 0.7` 播放，不是改用合成音。
- 動詞表／形容詞表由 `tools/build_wordtables.py` 由各課單字自動生成 `data/wordtables.json`：動詞換算成原形＋ます形後分五段／一段／不規則，形容詞依 pos（い形／な形／形容動詞）分類。單字表的假名時而寫ます形、時而寫原形，改分類規則時兩個方向都要顧及。動詞原形音檔在 `audio/verb/`。
- 動詞表／形容詞表的音檔（`audio/verb/`、`audio/adj/`）生成後同樣要跑 `tools/trim_seq_audio.py audio/verb`、`... audio/adj`，剪完每段約 0.6 秒，「播放全部」才會緊湊。這兩個目錄用獨立版本號 `auVer()`（`?v=t1`），不要為它們去 bump `audio.json` 的 `v`，否則全部 60MB 音檔都要重下。
- 「播放全部」會用 `followRow()` 自動把當前播放的那一行捲到畫面中間（判斷只在跑出可視範圍時才捲，避免每 0.6 秒都動畫面）。
- 順序表的音檔（`audio/seq/`）用 `tools/trim_seq_audio.py` 剪掉前後靜音：edge-tts 原始檔每段尾隨約 1.1 秒空白，剪完後每段約 0.7 秒，「播放全部」才會緊湊。重跑 `make_seq_audio.py --force` 後要再跑一次 `trim_seq_audio.py --force`，並把 `data/audio.json` 的 `v` 加一，令瀏覽器重抓音檔。
- 音檔版本分三組，改一組不用重下 60MB：動詞／形容詞表 `?v=t1`、句子（會話／句型／文法／聽力）`?v=e2`、單字跟 `data/audio.json` 的 `v`。`make_audio.py --force-ex` 只重出句子；跑完把 `audio.json` 的 `v` 調回去，否則單字音檔會被迫重下。
- 驗證人聲有無接上：`python3 -m http.server 8899` 後跑 `python3 tools/check_audio_cdp.py http://127.0.0.1:8899/`（文法總表、課內文法、聽力、對話、跟讀逐項檢查是否播 mp3、有沒有落到 TTS）。
- Service Worker 採網路優先：有新版本時直接更新，離線時才回退到快取。
- 進度鍵為 `ngs-progress-v1`，只記錄已完成課數與各段是否看過。
